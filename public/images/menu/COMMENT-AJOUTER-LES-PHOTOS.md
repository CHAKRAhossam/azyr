# 📸 Comment ajouter les photos des produits du menu

Chaque produit affiche automatiquement sa photo dès qu'un fichier au bon nom
est déposé dans le bon dossier. Aucun code à modifier.

## Règles

- **Format :** `.jpg` (idéalement ~1200×900 px, cadrage paysage 4/3).
- **Emplacement :** `public/images/menu/<catégorie>/<nom-du-fichier>.jpg`
- Respecter EXACTEMENT le nom de fichier ci-dessous (minuscules, tirets, sans accents).
- Tant qu'une photo manque, le produit reste affiché proprement (pas d'image cassée).
- Après avoir ajouté les photos : `git add`, `git commit`, `git push` → elles apparaissent en ligne.
